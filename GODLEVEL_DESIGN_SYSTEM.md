## Philosophy: Maximum Anti-AI-Slop Defense

This is the ULTIMATE design system combining 5 god-tier frameworks:

1. **UI Craft (52 deterministic gates)** - Design engineering system from Stripe/Linear/Vercel patterns
2. **Hallmark (58 anti-slop gates)** - Structural variety, honest copy, locked tokens
3. **Neo-Brutalism 2026** - Hard shadows, thick borders, intentional rawness
4. **Taste Skill v2** - Spacing discipline, anti-patterns, motion rules
5. **Impeccable (59 detector rules)** - Visual hierarchy, contrast, accessibility

**Core Principle:** 110 combined gates ensure ZERO AI-slop. Every output must pass all gates.

## The 110 Combined Anti-Slop Gates

### UI Craft Gates (52 Total)

#### Visual Slop (43 rules from ui-craft-detect)

**Critical Violations (-8 points each):**
1. ❌ `purple-cyan-gradient` - Purple-to-blue mesh gradient
2. ❌ `glassmorphism-stack` - Backdrop blur on structural cards
3. ❌ `animate-bounce` - Bounce/elastic easing on UI transitions
4. ❌ `left-top-animation` - Decorative gradient blobs
5. ❌ `transition-all` - Animating all properties (performance killer)
6. ❌ `absolute-zindex` - Random z-index values (not from scale)
7. ❌ `no-focus-visible` - Missing focus outlines
8. ❌ `outline-none-no-replacement` - Removing focus without replacement

9. ❌ `gradient-text-metric` - Gradient fill on important numbers

11. ❌ `emoji-feature-icon` - Emoji as primary icon system

14. ❌ `pure-black-text` - Pure #000 black text

16. ❌ `pixel-radius-inconsistency` - Border radius not from scale
17. ❌ `inline-any-style` - Inline styles instead of tokens

**Warning Violations (-1 point each):**
18. ❌ `setTimeout-animation` - Animation timing with setTimeout
19. ❌ Forms: `placeholder-as-label` - Placeholder instead of label
20. ❌ Forms: Missing error states
21. ❌ Forms: No disabled styling

## Design Tokens (God-Level System)

### Typography Hierarchy (UI Craft Standard)
```css
:root {
  /* Font Families (Max 2 + 1 Code) */
  --font-display: 'Space Grotesk', sans-serif;  /* 700 weight only */
  --font-body: 'Inter', sans-serif;             /* 400-600 weight */
  --font-code: 'JetBrains Mono', monospace;     /* 400-700 weight */
  
  /* Size Scale (Responsive) */
  --text-display: clamp(3.5rem, 8vw, 6rem);     /* 56-96px */
  --text-4xl: clamp(2.5rem, 5vw, 4rem);         /* 40-64px */
  --text-3xl: clamp(2rem, 4vw, 3rem);           /* 32-48px */
  --text-2xl: clamp(1.5rem, 3vw, 2rem);         /* 24-32px */
  --text-xl: 1.25rem;                            /* 20px */
  --text-lg: 1.125rem;                           /* 18px */
  --text-base: 1rem;                             /* 16px */
  --text-sm: 0.875rem;                           /* 14px - MINIMUM */
  --text-xs: 0.75rem;                            /* 12px - labels only */
  
  /* Line Heights (Taste Skill Standard) */
  --leading-tight: 1.1;      /* Display headings */
  --leading-snug: 1.3;       /* H1-H3 */
  --leading-normal: 1.5;     /* Body text MINIMUM */
  --leading-relaxed: 1.6;    /* Long-form content */
  --leading-loose: 1.75;     /* Code blocks */
}
```

### Motion (UI Craft + Taste Skill)
```css
:root {
  /* Durations (Fast, Not Slow) */
  --dur-instant: 0ms;
  --dur-fast: 150ms;         /* Snappy interactions */
  --dur-normal: 200ms;       /* Standard transitions */
  --dur-slow: 300ms;         /* MAXIMUM allowed */
  
  /* Easings (NO BOUNCE, NO ELASTIC, NO CUBIC-BEZIER) */
  --ease-linear: linear;
  --ease-out: ease-out;
  --ease-in: ease-in;
  --ease-in-out: ease-in-out;
  
  /* Transforms (Hover Lifts) */
  --lift-sm: translateY(-2px);
  --lift-md: translateY(-4px);
  --lift-lg: translateY(-6px);
  
  /* Press Down */
  --press: translateY(2px);
}

/* CRITICAL: Reduced Motion Override */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

## Component Patterns (Production-Ready)

### Buttons (8-State System + UI Craft)
```css
.btn {
  /* Base State */
  height: var(--button-height);        /* 56px minimum */
  padding: 0 var(--space-xl);
  font-family: var(--font-display);
  font-size: var(--text-lg);
  font-weight: 700;
  border: var(--border-width-thick) solid var(--color-black);
  border-radius: var(--radius-md);
  background: var(--color-black);
  color: var(--color-white);
  box-shadow: var(--shadow-lg);
  cursor: pointer;
  transition: all var(--dur-fast) var(--ease-out);
  
  /* NO transition-all (-8 UI Craft penalty) */
  /* Use specific properties instead */
  transition-property: transform, box-shadow, background-color;
}

/* Hover - Lift + Shadow Increase */
.btn:hover {
  transform: var(--lift-md);
  box-shadow: var(--shadow-xl);
}

/* Focus - Visible Ring (NO ANIMATION DELAY) */
.btn:focus-visible {
  outline: 3px solid var(--color-primary);
  outline-offset: 2px;
  /* Instant appearance - NO transition delay */
}

/* Active - Press Down */
.btn:active {
  transform: var(--press);
  box-shadow: var(--shadow-sm);
}

/* Disabled - Clear Visual Change */
.btn:disabled {
  opacity: 0.5;
  cursor: not-allowed;
  transform: none;
  box-shadow: var(--shadow-md);
}

/* Loading State */
.btn[data-state="loading"] {
  position: relative;
  color: transparent;
  pointer-events: none;
}
.btn[data-state="loading"]::after {
  content: '';
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 20px;
  height: 20px;
  border: 3px solid var(--color-white);
  border-top-color: transparent;
  border-radius: 50%;
  animation: spin 0.6s linear infinite;
}

/* Success State */
.btn[data-state="success"] {
  background: var(--color-success);
  border-color: var(--color-black);
  color: var(--color-black);
  box-shadow: var(--shadow-success);
}

/* Error State */
.btn[data-state="error"] {
  background: var(--color-error);
  border-color: var(--color-black);
  color: var(--color-white);
  box-shadow: var(--shadow-error);
  animation: shake 0.3s;
}

@keyframes spin {
  to { transform: translate(-50%, -50%) rotate(360deg); }
}

@keyframes shake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-4px); }
  75% { transform: translateX(4px); }
}
```

### Forms (UI Craft + Accessibility)
```css
/* Input Fields */
.input {
  height: var(--input-height);          /* 48px minimum */
  padding: 0 var(--space-lg);
  font-size: var(--text-base);
  border: var(--border-width-thick) solid var(--color-black);
  border-radius: var(--radius-md);
  background: var(--color-white);
  transition-property: border-color, box-shadow;
  transition-duration: var(--dur-fast);
}

.input:focus {
  outline: none;
  border-color: var(--color-primary);
  box-shadow: 0 0 0 3px oklch(55% 0.22 260 / 0.2);
}

/* Error State (MUST have describedby) */
.input[aria-invalid="true"] {
  border-color: var(--color-error);
  box-shadow: var(--shadow-error);
}

/* Error Message (Required by UI Craft) */
.error-message {
  margin-top: var(--space-sm);
  color: var(--color-error);
  font-size: var(--text-sm);
  display: flex;
  align-items: center;
  gap: var(--space-xs);
}

/* Label (NEVER use placeholder as label) */
.label {
  display: block;
  margin-bottom: var(--space-sm);
  font-weight: 600;
  font-size: var(--text-sm);
  color: var(--color-text-primary);
}

/* Disabled State (Must be visually distinct) */
.input:disabled {
  opacity: 0.5;
  cursor: not-allowed;
  background: var(--color-paper-2);
}
```

## Pre-Flight Checklist (110 Gates)

Run this before EVERY commit:

### ✅ UI Craft Score (Target: 90+/100)
- [ ] Anti-slop score: ≥ 85 (0 critical violations)
- [ ] Token discipline: 100 (zero inline hex/styles)
- [ ] A11y static: 100 (all images have alt, semantic HTML)
- [ ] Overall UICraftScore: ≥ 90 (Grade A)

### ✅ Typography (Hallmark + UI Craft)
- [ ] Max 2 fonts (display + body) or 3 with code
- [ ] NO italic headers anywhere
- [ ] Headlines ≤ 7 words or size-adjusted
- [ ] Body measure ≤ 75 characters
- [ ] Line height ≥ 1.5 for body, 1.1-1.3 for headings
- [ ] Font size ≥ 14px for body text

### ✅ Color & Contrast (WCAG AA + Neo-Brutalist)
- [ ] All text ≥ 4.5:1 contrast
- [ ] Large text ≥ 3:1 contrast
- [ ] NO pure black (#000) on text (use tinted black)
- [ ] All colors reference tokens (NO inline hex)
- [ ] Borders are pure black or accent colors
- [ ] NO gradients anywhere

### ✅ Spacing & Layout (Taste Skill)
- [ ] Section gaps ≥ 64px
- [ ] Card padding ≥ 32px
- [ ] Component gaps ≥ 24px
- [ ] Touch targets ≥ 44px height
- [ ] NO horizontal scroll on mobile
- [ ] NO nested cards
- [ ] NO centered layouts without max-width

### ✅ Interaction States (UI Craft 8-State)
- [ ] Default, hover, focus, active, disabled, loading, error, success
- [ ] Focus outlines ≥ 3px, ≥ 3:1 contrast
- [ ] Focus appears INSTANTLY (NO animation delay)
- [ ] Hover: lift + shadow increase
- [ ] Active: press down effect
- [ ] Loading: skeleton or spinner
- [ ] Error: clear visual indicator + message
- [ ] Success: confirmation feedback

### ✅ Motion & Animation (UI Craft + Reduced Motion)
- [ ] Transitions ≤ 300ms (prefer 150-200ms)
- [ ] Only transform/opacity animated (NO width/height/margin)
- [ ] NO bounce or elastic easing
- [ ] NO cubic-bezier curves (use linear/ease-out)
- [ ] `prefers-reduced-motion` implemented
- [ ] NO animation on focus rings

### ✅ Neo-Brutalist Checks
- [ ] ALL shadows are hard (blur-radius: 0)
- [ ] ALL borders are 2-4px solid black
- [ ] Border radius ≤ 4px (prefer 0px)
- [ ] NO soft/subtle/pastel colors
- [ ] NO transparency (opacity: 1 always)
- [ ] Cards have offset box-shadow (4-8px)

### ✅ Anti-Slop Checks (Hallmark)
- [ ] ZERO em-dashes (—) anywhere
- [ ] Different macrostructure from last build
- [ ] Different theme (or differs on ≥1 axis)
- [ ] NO invented metrics or fake testimonials
- [ ] NO "clean and modern" / "revolutionize" boilerplate
- [ ] NO Inter font as lazy default
- [ ] NO purple-to-blue gradients
- [ ] NO side-tab borders
- [ ] NO fake browser chrome
- [ ] NO section numbering (01 · 02 · 03)

### ✅ UI Craft Specific
- [ ] NO `transition-all` anywhere
- [ ] NO `setTimeout` for animations
- [ ] NO placeholder-as-label pattern
- [ ] NO div with onClick (use button/semantic HTML)
- [ ] NO modal without <dialog> element
- [ ] NO emoji in aria-labels
- [ ] NO positive tabIndex values
- [ ] Tables have overflow handling
- [ ] Images have alt text
- [ ] Forms have proper error states with describedby

## CI Integration (Optional but Recommended)

### Install ui-craft-detect
```bash
npm install -D ui-craft-detect
```

### Add to package.json
```json
{
  "scripts": {
    "lint:ui": "ui-craft-detect src/**/*.{tsx,jsx,html}",
    "build": "npm run lint:ui && your-build-command"
  }
}
```

### Fail Build on Score < 70
```bash
ui-craft-detect src/ --threshold 80 --json
```
